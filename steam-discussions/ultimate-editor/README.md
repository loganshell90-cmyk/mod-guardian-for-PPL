Ultimate Editor - Steam discussion posts
========================================

Ready-to-paste posts for the Ultimate Editor Workshop page. They use Steam's
BBCode ([b], [h1], [list]...), so paste them as-is into a new discussion.

Replace everything in [square brackets with words like THIS] before posting.

Suggested setup (pin the first one):
  1. 01-start-here.txt        Pinned hub that links to the other threads
  2. 02-bug-reports.txt       Where people report bugs
  3. 03-feedback.txt          What people like / don't like / want
  4. 04-how-to-use.txt        Guide + FAQ
  5. 05-backup-guide.txt      How to back up creations before updating
  6. 06-weekly-update.txt     Copy this every week for the update post

How to post: Workshop page -> Discussions -> Start a New Discussion -> paste
the title line as the title and the rest as the body. After posting, copy each
thread's link into the [LINK] spots in 01-start-here.txt and edit that post.
